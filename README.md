This program forecasts a game launch's hourly Twitch viewers from the first hour's count and the release-day curves of past launches. It outputs calibrated quantiles using a similarity-weighted empirical distribution blended with persistence.

## Run it

```sh
MAKEFUN_INPUT_DIR=/path/to/input MAKEFUN_OUTPUT_DIR=/path/to/output python3 -P -s main.py
```
